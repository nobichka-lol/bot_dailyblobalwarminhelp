# bot_dailyblobalwarminhelp
Этот код написан для бота, который ежедневно присылает в течении 30 дней полезные экологичные советы, если код запущен на устройстве.  
Бот каждый день отправляет эко-советы и мемы если написать команду, чтобы сделать жизнь чуть более экологичной и веселее.

# Команды

/start — приветствие и регистрация в боте 
/mem — получить случайный мем

# Запуск

1. Установи зависимости:
pip install pyTelegramBotAPI

2. Создай файл config.py и добавь токен:
token = "ваш_токен_здесь"

3. Положи мемы в папку images/

4. Запусти бота:
python bot.py

# Важно

- После каждого перезапуска бота нужно заново написать /start —
  иначе бот не будет знать о тебе и не пришлёт ежедневный совет
- Статистика и список пользователей хранятся только в памяти
  и сбрасываются при перезапуске
- Ежедневные советы отправляются в 11:50 — убедись что бот
  запущен в это время
